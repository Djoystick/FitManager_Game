## Implementation Steps

### Step 1: Create `updateTeamTactic` server action
**File:** `app/actions/lineupActions.ts`
- Add function `updateTeamTactic(tactic: string)` that updates the `tactic` column in `teams` for the current user (via cookie auth `tg_user_id`)
- Pattern: same as existing `updateTeamFormation` (line 137-179)

### Step 2: Wire tactics into `resolveMatch`
**File:** `app/actions/matchActions.ts`
- In `resolveMatch`, after fetching match data (line ~196), fetch both teams' `tactic` column from `teams` table
- Pass `homeTactic` and `awayTactic` to `runMatchEngine(...)` call at line 349
- The engine call becomes: `runMatchEngine(homeLineup, awayLineup, homeBench, awayBench, homeGreen, awayGreen, homeTactic, awayTactic)`

### Step 3: Add Tactic Selector UI to Lineup page
**File:** `app/lineup/page.tsx`
- Add `tactic` to `Team` interface (line 50-55)
- Add `activeTactic` state (line ~77)
- Load tactic from `team.tactic` in `fetchTeamData` (line ~139)
- Add a tactic selector section in the INFO tab (after formation selector area, around line ~650)
- Tactic selector: horizontal scrollable row of 6 tactic pills, similar to formation selector pattern
- On select: call `updateTeamTactic` and update local state
- Use dictionary keys for tactic names

### Step 4: Update MatchReportModal for tactics + new events
**File:** `components/MatchReportModal.tsx`
- **Tactics display:** Add a row below the score showing each team's tactic with an icon
- **New event icons** (replace default AlertCircle fallback):
  - `offside` → `Flag` icon (yellow/orange)
  - `crossbar` → `Target` with strike-through or `CircleDot` (cyan)
  - `own_goal` → `AlertTriangle` (red)
  - `penalty_save` → `Shield` with check (green)
  - `second_yellow` → `Square` stacked or `AlertCircle` (yellow)
- All icons from `lucide-react` only, styled with neon/glassmorphic CSS

### Step 5: Add dictionary keys for tactics
**File:** `lib/dictionaries.ts`
- Add keys for each tactic description (EN + RU):
  - `tactic_tiki_taka`, `tactic_counter`, `tactic_high_press`, `tactic_park_bus`, `tactic_wing_play`, `tactic_balanced`
  - `tactic_label`: "TACTIC" / "ТАКТИКА"
  - Match report event labels for new event types
