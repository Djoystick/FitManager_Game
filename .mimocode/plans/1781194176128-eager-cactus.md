## Root Cause
The page uses `overflow-y-auto custom-scrollbar` on the root div, treating the dashboard as a scrollable feed. This contradicts the 100dvh single-screen TMA UX constraint.

---

## Proposed Solution: Flex-Based Single-Screen Layout

### Core Principle
Replace scrollable feed with a **flex-column, `overflow-hidden` container** where each section gets a **fixed or flex-allocated height**. No section scrolls — everything fits in one viewport.

### Proposed React Component Tree
```
<div className="h-full flex flex-col overflow-hidden">          ← NEW: no scroll
  <GlobalHeader />                                              ← existing, ~125px
  <PageTransitionWrapper>
    <div className="flex-1 flex flex-col min-h-0 px-3 py-2 gap-2 overflow-hidden">
      
      {/* Row 1: Franchise Card — compact, ~70px */}
      <FranchiseCard />
      
      {/* Row 2: Core Focus — countdown/scout CTA, ~80px */}
      <CoreFocusSection />                                       ← CHANGED

```

## Tailwind CSS Strategy

### Root Container (page.tsx)
```tsx
// BEFORE:
<div className="h-full flex flex-col overflow-y-auto custom-scrollbar text-white relative"
     style={{ paddingBottom: '90px', background: '#05060f' }}>

// AFTER:
<div className="h-full flex flex-col overflow-hidden text-white relative"
     style={{ background: '#05060f' }}>
```

### Content Area
```tsx
// Each section uses flex-shrink-0 with fixed height
// The spacer div uses flex-1 to fill remaining space
<div className="flex-1 flex flex-col min-h-0 px-3 py-2 gap-2 overflow-hidden">
  {sections.map(s => <div className="flex-shrink-0">{s}</div>)}
  <div className="flex-1" />  {/* fills remaining space */}
</div>
```

### Key CSS Classes
- `h-full` — fills parent height (100dvh chain from layout)
- `flex flex-col` — vertical flex layout
- `overflow-hidden` — **CRITICAL**: prevents any scrolling
- `min-h-0` — **CRITICAL**: allows flex children to shrink below content size
- `flex-shrink-0` — sections maintain their height, don't compress
- `flex-1` — spacer absorbs all remaining vertical space
