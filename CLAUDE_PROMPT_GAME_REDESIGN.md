# Prompt for Claude IDE / Cursor: Полный редизайн интерфейса FitManager Game

**Роль:** Ты — Senior Frontend Engineer и UI/UX Архитектор мирового уровня, специализирующийся на разработке премиальных интерфейсов для Telegram Mini Apps (TMA) и Web3-игр. 

**Твоя задача:** Произвести полный редизайн веб-приложения игры `fitmanager_game`. Текущий дизайн выглядит слишком простым, имеет много пустых зон и не передает атмосферу футуристичного киберпанк/Web3-менеджера. Необходимо переделать интерфейс в стиле **Midnight Command Center** (дашборд космического корабля / крипто-терминал).

**Ключевые требования к новому дизайну (TMA-First):**
1. **Максимальная плотность и информативность:** Избавься от огромных отступов и пустых черных/белых экранов. Экран телефона должен быть плотно упакован полезными данными (графики, статы игроков, таймеры, ресурсы).
2. **Адаптация под Telegram Mini App:** Приложение работает внутри Telegram. Используй жесткий `100dvh` layout без скролла всей страницы (скроллиться должны только внутренние списки, например, состав команды). Нижний таб-бар должен быть всегда на виду.
3. **Midnight Command Center Aesthetics:**
   - Фон: глубокий `Midnight Abyss` (`#05060f`).
   - Акценты: неоново-фиолетовый, неоново-голубой, циановый.
   - Окна и карточки: стекломорфизм (frosted glass) — полупрозрачные фоны `bg-white/5` с размытием `backdrop-blur-md` и сложными внутренними тенями (inset shadows).
   - Градиенты: тонкие градиентные рамки (border-image или absolute псевдоэлементы) для подсветки активных элементов.
   - Шрифт: `Orbitron` (или `Space Grotesk`) для заголовков и цифр, `Inter` для мелкого текста.
4. **Вау-эффект и Микроанимации:** Обильное использование `framer-motion`. Карточки должны плавно появляться, цифры должны анимированно пересчитываться. Кнопки при нажатии должны иметь тактильный эффект (scale down) и свечение (glow).
5. **Многослойность (Elevation):** Карточки не должны быть просто плоскими квадратами. Используй светящиеся границы, градиентные подложки, иконки Lucide React с неоновым свечением (`drop-shadow`).

**Что конкретно нужно переделать:**
- **Главный Dashboard (`app/page.tsx`):** Сделать компактнее. Уместить блок команды (франшизы), таймер следующего матча и горизонтальный скролл (карусель) истории матчей без необходимости листать страницу вниз.
- **Экран Состава (`/lineup`):** Футуристичное футбольное поле с позициями. Игроки должны выглядеть как голографические карточки с гексагонами статов.
- **Экран Рынка (`/market`):** Как криптовалютная биржа. Тикеры, графики цен, плотные списки игроков, выставленных на продажу.
- **Навигация:** Нижний TabBar (Меню) должен выглядеть как стеклянная панель, парящая над фоном.

**Технические ограничения:**
- Стек: Next.js (App Router), React 19, Tailwind CSS, Framer Motion, Lucide React.
- База данных Supabase уже подключена — **логику получения данных не ломать**, изменять только визуальную часть (`className`, структуру DOM, добавление motion-оберток).
- Все цвета и эффекты выноси в классы Tailwind (используй произвольные значения `bg-[#05060f]`, `shadow-[...]` или добавь их в `tailwind.config.ts`).

**Критерий успеха:**
При открытии игры внутри Telegram у пользователя должна отвисать челюсть от уровня продакшена. Это должен быть самый красивый, плотный и современный интерфейс в экосистеме TON.

Действуй пошагово. Начни с переработки `app/layout.tsx` (фоны и шрифты), затем глобального TabBar, затем главного дашборда (`app/page.tsx`).
