# Prompt for Claude IDE / Cursor: Полный редизайн интерфейса FitManager Game

**Роль:** Ты — Senior Frontend Engineer и UI/UX Архитектор мирового уровня, специализирующийся на разработке премиальных интерфейсов для Telegram Mini Apps (TMA) и Web3-игр. 

**Твоя задача:** Произвести полный редизайн веб-приложения игры `fitmanager_game`. Текущий дизайн выглядит слишком простым, имеет много пустых зон и не передает атмосферу футуристичного киберпанк/Web3-менеджера. Необходимо подогнать интерфейс под дизайн-систему лендинга (Midnight Command Center).

**Ключевые требования к новому дизайну (TMA-First):**
1. **Жесткий Single-Screen Layout (NO SCROLL):** Весь интерфейс (кроме страниц Лиги и Рынка, где списки длинные) должен умещаться ровно в один экран `100dvh` без вертикального скролла всей страницы! Нижний таб-бар должен быть всегда зафиксирован внизу. Избавься от пустых черных дыр, плотно упакуй элементы.
2. **Дизайн в стиле Сайта (Midnight Command Center):**
   - Фон: глубокий `Midnight Abyss` (`#05060f`).
   - Акценты: неоново-фиолетовый, циановый.
   - Окна и карточки: стекломорфизм (frosted glass) — полупрозрачные фоны `bg-white/5` с размытием `backdrop-blur-md` и сложными внутренними тенями (inset shadows).
   - Шрифты: `Orbitron` (или `Space Grotesk`) для заголовков и цифр, `Inter` для мелкого текста.
3. **Плавность и Анимации:** Сделать **очень плавные** переходы между всеми экранами приложения (page transitions) и при открытии/закрытии модальных окон, используя `framer-motion` (AnimatePresence). 
4. **Ограниченное использование каруселей:** Используй горизонтальные карусели только там, где это логически оправдано (например, карточки прошедших и предстоящих матчей), чтобы сэкономить место по вертикали.

**Что конкретно нужно переделать (Сохраняя логику Supabase!):**
- **Главный Dashboard (`app/page.tsx`):** Должен умещаться в один экран! Размести блок команды, таймер, историю сыгранных матчей и **расписание предстоящих матчей**. 
  - По клику на сыгранный матч должна вызываться модалка статистики (MatchReportModal).
  - По клику на предстоящий матч (расписание) должна вызываться модалка скаутинга (OpponentScoutModal). Логика уже есть, главное не сломай её при редизайне.
- **Экран Профиля (`/profile`):** Полностью переработать в футуристичный дашборд менеджера, без пустых мест.
- **Состав (`/lineup`):** Футуристичное поле. Игроки — голографические карточки с гексагонами статов. Всё на одном экране.
- **Экран Рынка (`/market`):** В стиле криптобиржи. Тикеры, графики цен. Разрешен вертикальный скролл только внутри самого списка.
- **Лига (`/league`):** Разрешен вертикальный скролл таблицы. Сама таблица не должна быть сильно растянута вбок (сделай колонки компактнее, чтобы не приходилось свайпать вправо на телефоне, либо используй продуманный overflow-x).

Действуй пошагово: начни с `app/layout.tsx` (фоны, шрифты, page transitions), затем глобальный TabBar, затем `app/page.tsx`, затем остальные страницы.
