# Предложения по устранению логических тупиков (Fix Proposals)

## 1. Фикс Зомби-пенсионеров
**Файл:** `app/actions/matchActions.ts` (функция `getSquad`)
**Решение:**
Добавить фильтр `!p.is_retired` вместе с фильтром травм.
```typescript
let starters = players.filter(
  p => p.lineup_slot !== null && parseInt(p.lineup_slot) <= 10 && !p.is_injured && !p.is_retired
);
```
И то же самое в Fallback logic:
```typescript
const allHealthy = players.filter(p => !p.is_injured && !p.is_retired).sort(...);
```
Если после этого фильтра набирается меньше 11 игроков (а пенсионеров ставить нельзя), команда получает **техническое поражение (Technical Forfeit)**. Это заставит игроков следить за сменой поколений и подписывать молодых из Академии.

## 2. Смягчение Спирали смерти (Death Spiral)
**Файл:** `app/actions/matchActions.ts`
**Решение:**
Сейчас при нулевом балансе выносливость команды сбрасывается до 30. Это слишком жестоко. Мы можем сделать два варианта:
- **Вариант А:** Сбрасывать до `50` (чтобы штраф в матче был меньше, и был шанс выиграть или сыграть вничью).
- **Вариант Б (Страховка для новичков):** Если у команды Стадион 1 уровня (новички), то штраф при банкротстве не применяется, либо стамина падает только до 70.

## 3. Свободные агенты (Увольнение при банкротстве)
**Механика:** Добавить возможность вручную расторгать контракты с игроками через интерфейс команды (увольнение), чтобы менеджер мог добровольно скинуть "дорогой балласт" и спасти клуб от банкротства. 
Для этого нужно добавить кнопку "Уволить" в профиле игрока (устанавливает `team_id = null` или удаляет карточку).
